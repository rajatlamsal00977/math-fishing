# Math Fishing Game — Build Plan

A K–5 math learning game inspired by *Cast n Chill* (Steam). Solo hackathon submission for the Nerdy AI Hackathon. Target submission date: **Sep 18**. Target demo length: **2–3 minutes**.

---

## 1. Product Vision

A cozy 2D top-down fishing game where children (grades K–5) practice arithmetic by catching fish. Every fish species maps to a math skill and difficulty tier. Solving the problem *is* the reeling mini-game — get the answer right, the fish comes closer; get it wrong, the tension spikes and the fish may escape.

The AI layer is what makes this different from Prodigy Math or IXL:
- Every math problem is **generated fresh** by Claude, conditioned on the specific fish species and the child's current skill state
- **Adaptive spawning**: the ocean itself re-populates with fish types the child needs to practice
- **Legendary fish lore**: rare catches get a unique flavor-text description generated by Claude, tying the math concept to the fish

Aesthetic goal: this should feel like the *anti-Prodigy Math*. No harsh error sounds. No red X's. Warm pixel-art palette. Nature ambience. Kids should want to open it because it's calming, not because a streak is at stake.

---

## 2. Core Game Loop

1. Player sails their boat around a bounded 2D pond (top-down view)
2. Underwater cutaway shows fish swimming below the surface — the player can *see* what's around
3. Player positions boat near a fish and casts
4. Fish bites → **reeling mini-game begins**:
   - A math problem appears in a wooden-frame panel
   - A tension bar on the side rises slowly
   - Correct answer → fish moves closer, tension drops, problem may repeat with a new question until fully reeled in (3 correct answers = caught)
   - Wrong answer → tension spikes; 3 wrong = fish escapes with a friendly "Nice try!"
5. Caught fish → coin reward + fish added to Fish Guide + XP toward next area
6. Player returns to dock → sells fish for coins → buys rod/boat upgrades → unlocks new areas

The loop should take **30–60 seconds per catch**. Snappy, not slow.

---

## 3. Tech Stack

- **Phaser 3** (game engine, 2D, well-suited for this)
- **Vite** (dev server + build)
- **TypeScript** (recommended, but JS is fine if faster)
- **Vercel** for hosting (static site)
- **Vercel Serverless Function** to proxy Claude API calls (hides the API key — critical, never expose it client-side)
- **Claude API** (`claude-sonnet-4-6` model, cheap and fast enough for this)
- **LocalStorage** for save data (no backend DB needed)

No React shell needed — keep everything in Phaser to reduce integration complexity. Use Phaser's built-in UI system or HTML overlay elements positioned over the canvas for the answer input.

**Answer input UX**: use a big touch-friendly number pad (0–9, backspace, submit), not keyboard input. Works on tablets, better for K–5 fine motor skills.

---

## 4. Visual & Audio Design

**Do not generate pixel art with AI** — it will look inconsistent. Fetch cohesive free assets:

- Fish sprites, boat, water tiles, UI: **Kenney.nl** (CC0, no attribution) or **itch.io** free packs
- Recommended packs: Kenney "Fish Pack," "Pixel UI Pack," any pixel water/ocean tileset from itch.io
- If a specific fish species isn't available, recolor an existing sprite in a pixel editor (Aseprite trial or free Piskel)

**Audio**:
- Ambient: water lapping + occasional bird chirps (freesound.org, CC0 preferred)
- Catch jingle: short pleasant chime (Kenney "Interface Sounds")
- No harsh negative-feedback sounds. A wrong answer gets a soft *plunk*, not a buzzer

**Color palette**: warm, low-saturation. Blues and greens dominant, wood-tone UI panels. Avoid neon "kid app" colors.

## 5. Detailed Game Mechanics

### Boat & Camera
- Top-down view
- Boat moves with arrow keys / WASD (and on-screen d-pad for touch)
- Camera follows boat, bounded by pond edges
- Movement is slow and floaty — this is cozy, not action

### Underwater View
- Below the water surface, render fish sprites swimming in gentle patterns
- Fish are **visible** — the player sees them and chooses which to fish for
- Fish size on-screen roughly correlates to difficulty (big shadow = hard problem = big reward)
- Fish schools of 4–6 visible at a time; if one is caught or escapes, respawn nearby after a delay

### Casting
- Player positions boat near a visible fish, presses SPACE / taps a "Cast" button
- Line drops from the boat; if a fish is within range, it takes the bait after 1–3 seconds
- If no fish bites in 5 seconds, line auto-retracts

### Reeling Mini-Game (the core)
- On bite: game state switches to "reeling" — boat locks in place, camera zooms slightly
- A wooden-frame panel appears with:
  - The math problem (large, readable text)
  - Number pad (0–9, backspace, submit)
  - **Tension bar** on the right side, rising slowly (fills in ~15 seconds if idle)
- **Correct answer**: fish sprite moves closer to boat, tension bar drops significantly, new problem generated. Need **3 correct** to fully reel in.
- **Wrong answer**: tension bar spikes upward, gentle *plunk* sound. Player can retry the same problem.
- **3 wrong answers total** or **tension bar full**: fish escapes. Show "Nice try! That one got away." Return to sail mode. No score penalty — losses should feel neutral, not punishing.
- **Success**: catch animation, coin reward, fish added to guide

## 6. Fish Species (MVP: 5 + 1 legendary)

Each species has: name, sprite, math topic, difficulty band, base coin value, rarity (spawn weight).

| Species | Topic | Difficulty | Coins | Rarity |
|---|---|---|---|---|
| Guppy | Single-digit addition (e.g., 3 + 5) | Easy | 5 | Common |
| Bluegill | Single-digit subtraction (e.g., 9 − 4) | Easy | 8 | Common |
| Bass | Two-digit addition (e.g., 24 + 13) | Medium | 15 | Uncommon |
| Reef Regrouper | Two-digit subtraction with regrouping (e.g., 42 − 17) | Medium | 25 | Uncommon |
| Deep Trout | Simple multiplication (e.g., 6 × 4) | Hard | 40 | Rare |
| **Golden Marlin** (Legendary) | Multi-step word problem | Legendary | 200 | Very Rare (1% spawn, once per session) |

The Golden Marlin is your **demo money-shot**. Spawn it deliberately during the demo recording.

## 7. Progression System

**Coins**:
- Earned by catching fish
- Spent at the dock shop (single NPC — Rusty)

**Rod upgrades** (buy in order):
- Starter Rod (default) — can catch Guppy, Bluegill, Bass
- Sturdy Rod (100 coins) — unlocks Reef Regrouper
- Deep-Sea Rod (300 coins) — unlocks Deep Trout, and access to the "Deep Waters" zone

**Zone unlocks**:
- Start: Shallows (only zone in MVP)
- Deep Waters (implied but not built in MVP — show as locked area on the map for demo purposes)

Save progress to LocalStorage so refreshes don't wipe state.

## 9. AI Integration (the whole point)

Three LLM calls, all routed through the Vercel serverless function proxy.

### 9a. Problem Generation

**When**: at the start of every reeling mini-game, and again for each of the 3 answers needed.

**Endpoint**: `POST /api/generate-problem`

**Request body**:
```json
{
  "species": "Reef Regrouper",
  "topic": "two-digit subtraction with regrouping",
  "difficultyBand": "medium",
  "recentAttempts": ["correct", "correct", "wrong"]
}
```

**Prompt to Claude** (system + user):
```
You generate math problems for a K–5 fishing game.

Fish species: {species}
Math topic: {topic}
Difficulty band: {easy|medium|hard}
Child's last 3 attempts on this topic: {recentAttempts}

Generate ONE age-appropriate arithmetic problem. Output ONLY valid JSON, no prose:

{
  "question": "string, kid-friendly wording, no more than 12 words",
  "answer": <integer>,
  "hint": "string, one gentle hint that does not give the answer"
}

Rules:
- Elementary reading level, no complex vocabulary
- Numbers appropriate to the difficulty band:
  - easy: single-digit results
  - medium: results up to 100
  - hard: word problems OR multi-step reasoning, results up to 200
- No negative numbers
- If the last 2 attempts were wrong, generate an EASIER problem within the same band
- Never repeat the exact same numbers as the previous problem
```

**Parse response**, validate JSON shape, use in the reeling UI. On parse failure, fall back to a hard-coded problem bank of ~20 problems per species.

### 9b. Adaptive Difficulty (no LLM call — pure logic)

Client-side rule engine tracks per-skill mastery:
- Per skill: track last 5 attempts, current difficulty band
- **3 correct in a row** → move up one band (easy → medium → hard)
- **2 wrong in a row** → move down one band
- Never drop below "easy"

Fish spawn weighting:
- Track a "practice need" score per skill: `1.0 - (recent_correct_rate)`
- When spawning a new fish in the pond, weight spawn probability by practice need across skills the player has unlocked
- Result: kids get more of what they're weak at, without it feeling forced

### 9c. Legendary Fish Lore

**When**: first time a player catches the Golden Marlin (or any future legendary).

**Endpoint**: `POST /api/generate-lore`

**Prompt**:
```
Write a one-sentence, playful description of this legendary fish for a K–5 fishing game.
Species: Golden Marlin
Math concept: multi-step word problems

The description should tie the fish's personality/trait to the math concept in a fun way.
Max 20 words. No quotes, just the sentence.
```

Cache the response in LocalStorage keyed by species name — regenerate only once per species per player.

## 10. UI/UX Rules

- **No punishment framing**. Wrong = soft plunk, encouraging text. Escape = "That one got away — try again!"
- **Big tap targets** for touch (44px minimum)
- **Readable text** — problems should be at least 24px, high contrast
- **One hint button per problem** — reveals the LLM-provided hint. No penalty for using it.
- **Auto-save** to LocalStorage after every catch
- **Skip animations gracefully** — never lock the player out for more than 2 seconds

## 12. Build Order

**Week 1 — Feel the loop**
1. Vite + Phaser + TypeScript scaffold, deploy empty "Hello" scene to Vercel
2. Boat movement in a bounded pond with placeholder assets
3. Static fish sprites swimming below in the underwater view
4. Casting mechanic — click a fish, line drops, "bite" triggers reeling scene
5. Reeling scene with a HARDCODED math problem, tension bar, submit button
6. Catch animation → return to pond, fish removed

1. Swap in real pixel art from Kenney/itch.io

3. Add all 5 fish species with correct topic/difficulty tags

5. Implement FishSpawner (adaptive spawn weighting)
6. Coin economy + dock shop with one upgrade
7. Fish Guide screen (basic grid + detail view)
8. Save/load via LocalStorage

**Week 3 — Polish + demo**
1. Add ambient audio, catch jingle, plunk sound
2. Add Golden Marlin legendary + lore generation
3. Visual polish: catch animations, transitions, particle effects on water
4. Tune numbers: difficulty progression, coin values, spawn rates (playtest with a child if possible)
5. Record demo video (2–3 min)
6. Write submission blurb
7. **Buffer: 2 full days** for bug fixes and unexpected issues

## 14. Success Criteria

- Loop is fun even without the math (feel-first)
- A judge watching for 2 minutes should immediately understand: cozy fishing game + math + AI adapts to the kid
- The Golden Marlin moment should draw a smile
- No crashes, no visible LLM errors, no API keys leaked
- Deployed to a public URL judges can try themselves

## Notes for the AI implementing this

- Prioritize **loop feel** over feature count. A polished 5-species game beats a buggy 15-species one.
- If any feature blows the schedule, cut it. Cut order: legendary lore → dock shop upgrades → Fish Guide detail view → adaptive spawning (leave adaptive difficulty in; it's the most demoable AI feature).
- Never expose the Anthropic API key in client-side code. All Claude calls go through `/api/*` serverless functions.
- Always have a fallback for LLM calls — if the API times out or returns malformed JSON, use the hard-coded problem bank.
- Test on mobile early — the target audience uses tablets.
